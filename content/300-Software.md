# Aims

1. Demystify software by summarizing how it works, and how it is created and maintained
2. Explain the relationship and interactions between the operating system,  apps and what you see on the screen (i.e., the user interface)
3. Provide strategies and demonstrate the hands-on skills needed to organize and manage files using the File System 
4. Demonstrate how you customize (i.e., *configure*) your device and the apps installed on it using Settings
# Objectives

1. Managing apps
	1. Vetting apps
	2. Installing & uninstalling apps
	3. Locating apps installed on your device
	4. Starting and stopping apps
	5. Finding help
		1. Finding an apps help guide
		2. Finding & vetting other sources
	6. Starting up apps when at OS boot-time
2. Working with files & folders
	1. File basics: finding, creating, opening, saving, copy/move, delete, sharing (this is a cloud thing)
	2. Folder basics: finding, creating, moving, renaming, deleting, sharing (this is a cloud thing)
	3. Strategies for organizing files & managing storage utilization (i.e., when and how to clean up/delete things) 
	4. Backup
	5. Include at least a note indicating there is more to know/learn about cloud storage and syncing
	6. Folders as a general construct
3. Orient you to UI (how to read the screen, identify & use common controls)
	1. Controls & icons -- identify & use
		1. Windows
			1. "Standard", dialog, wizard, ...
			2. Tabs
	2. Common actions/operations
		1. opening and closing files and apps
		2. copy/cut & paste
		3. select
		4. drag-and-drop
		5. resizing windows -- inc'l minimizing/maximizing
		6. Zoom in/out
4. Managing Settings
5. Strategies for diagnosing problems
# Scope

1. Overview
	1. basic definition, kinds of software, & categories of apps
	2. rationale for the sections in this part of the course
2. What is Software
	1. Kinds, types, and categories of software
		1. apps, widgets/applets, extensions, daemons, etc
		2. desktop vs mobile vs web apps
		3. file-based vs database-based
		4. [[301-App Store Categories]]
	2. The relationship between Software and Data
3. How Software Works
	1. What is a "process"
	2. The runtime lifecycle
	3. Processing types: batch, interactive, distributed, asynchronous
	4. Software states: background vs foreground, active vs hibernating, blocked/waiting
4. How Software is created and maintained (i.e., software lifecycle)
	1. Distribution models: "right to use", SaaS, PaaS, IaaS, FaaS, ...
5. What are operating systems
	1. The role of the operating system
	2. OS responsibilities: an overview of [[201-OS Subsystems]]
	3. Kinds & types of operating systems
		1. single-user, multi-user, desktop/mobile/server, multicomputer, distributed, embedded, real-time, hypervisor
6. The relationship between apps, operating systems, and hardware: 
	1. how apps interact with the OS and how the OS interacts with device hardware
	2. OS runtime lifecycle: boot, app launch, manage, app shutdown, os shutdown
7. User Interfaces
	1. Definition, role, and responsibilities

		3. backup
